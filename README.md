# Product-Description-Generator
A sleek, dark-themed Chrome extension that uses the Google Gemini API to instantly generate compelling, SEO-friendly product descriptions.

## Overview
This Chrome extension provides a simple and powerful interface for generating high-quality product descriptions using artificial intelligence. Designed with a clean, futuristic, dark/neon theme, it allows users to quickly input a product name and keywords to generate creative and persuasive copy, which can then be copied as clean HTML for use in e-commerce platforms like Shopify.

This tool is perfect for e-commerce managers, marketers, and copywriters looking to streamline their workflow and create engaging product listings without needing to be logged into a specific platform.

## Project Files
- manifest.json: The core configuration file for the Chrome extension.

- popup.html: The HTML structure for the extension's user interface.

- popup.css: The stylesheet that creates the dark, futuristic theme.

- popup.js: The JavaScript file containing all logic, including the API call to Google Gemini.

- images/: Folder containing the icons for the extension (icon16.png, icon48.png, icon128.png).
